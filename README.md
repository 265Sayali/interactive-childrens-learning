# Interactive Children's Learning

A Java-based interactive web application designed to make learning engaging for children through educational lessons, games, quizzes, and progress tracking.

## Features

- User registration and login
- Interactive learning modules
- Educational games
- Interactive quizzes
- Quiz and game score tracking
- Progress management
- Feedback functionality
- OTP/email functionality
- Admin functionality

## Learning Modules

- Letters
- Numbers
- Colors
- Animals
- Rhyming words

## Technology Stack

- Java
- JSP
- HTML
- CSS
- JavaScript
- Hibernate
- Apache Derby
- JavaMail
- Apache Ant
- NetBeans
- GlassFish

## Project Structure

```text
src/       Java source code and configuration
web/       JSP pages, games, quizzes, images and web resources
test/      Project tests
nbproject/ NetBeans project configuration
```

## Configuration and Security

This repository is prepared for public GitHub use.

Do not commit real passwords, API keys, email app passwords, database credentials, or local machine paths.

For local development, create a `.env` file from `.env.example` and provide your own configuration values. The `.env` file is ignored by Git.

## Database

The application uses Apache Derby. Configure your local Derby database and connection values according to your development environment.

## Running the Project

This project was originally developed as a Java web application using NetBeans/Ant and a GlassFish server.

1. Install a compatible JDK.
2. Install/configure NetBeans and GlassFish.
3. Configure Apache Derby.
4. Configure local environment values.
5. Open the project in NetBeans.
6. Build and deploy the application to GlassFish.
